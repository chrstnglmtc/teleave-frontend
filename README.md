# Teleave

Teleave is a web app designed to allow users to leave multiple Telegram groups and channels with ease. Instead of leaving them one by one, you can select the groups and channels you'd like to exit and leave them all in a single click. This is a useful tool for those who are part of many Telegram groups and want to manage their memberships more efficiently.

## Features
- **View all joined groups and channels**: A list of groups and channels that the user is part of.
- **Select groups/channels to leave**: Checkboxes allow users to select which groups/channels to leave.
- **Easy one-click exit**: Once selected, you can leave all chosen groups and channels in one go.
- **Telegram API Integration**: Utilizes the Telethon library to interact with Telegram and manage group memberships.

## Technologies Used
- **Frontend**: React, Vite, TypeScript
- **Backend**: FastAPI
- **Telegram API**: Telethon
- **Hosting**: Netlify (frontend) and FastAPI (backend)

## Deployment

You can access the live web app at [teleave.netlify.app](https://teleave.netlify.app).

## Setup and Installation

### Prerequisites
- Node.js (for the frontend)
- Python 3.x (for the backend)
- Telegram account (for login and interaction)
